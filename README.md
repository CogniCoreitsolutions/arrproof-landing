# ARRproof Landingpage

Statische Landingpage für ARRproof, eine Beratungsleistung der CogniCore IT Solutions GmbH.

- `index.html` mit eingebettetem CSS, keine Build-Schritte. Schrift Archivo über Google Fonts.
- `assets/` Favicon. Raleway und Logo stammen aus der ersten Fassung und werden von der Seite nicht mehr geladen.
- `img/` Ansichten aus dem MVP mit synthetischem Testdatensatz, aus der ersten Fassung, derzeit nicht eingebunden.

Veröffentlicht über GitHub Pages aus dem Branch `main` unter https://arrproof.com. Die Seite ist mit `noindex` markiert, bis Name, Marke und Angebot geklärt sind.
