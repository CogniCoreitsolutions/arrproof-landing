# ARRproof Landingpage

Statische Landingpage für ARRproof, ein Produkt der CogniCore IT Solutions GmbH.

- `index.html` mit eingebettetem CSS, keine Build-Schritte
- `img/` Ansichten aus dem MVP mit synthetischem Testdatensatz
- `assets/` Schrift (Raleway) und Logo

Veröffentlicht über GitHub Pages aus dem Branch `main`. Die Seite ist mit `noindex` markiert, bis Name und Marke geklärt sind.
